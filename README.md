# AeroRUL

Uncertainty-aware remaining useful life estimation for aircraft engines using NASA C-MAPSS sensor histories.

This repository will be developed one component at a time: reproducible data processing, baseline and temporal models, uncertainty evaluation, generalization experiments, and a deployable prediction service.

## Progress

See [the project deliverables](Deliverables/README.md) for the ordered checklist. Each stage starts as **UNDONE** and becomes **DONE** when its outputs and validation are complete.

The repository currently contains planning documents only; implementation and experiments have not started.
